# WSSI local assessment contract

Current measurement evidence and activation decision: [foreground acceptance and release budget](foreground-evidence.md).

Current authority: [WSSI canonical acceptance contract](acceptance-contract.md). Presentation consumers must read V8 accepted snapshots through `WSSISnapshotStore.acceptedCoverage`, then use `assessmentLayer(in:)` only for identified layers. `observedEmpty` has unknown issuance/validity and returns no assessment layer: expose unavailable forecast assessment with an empty-observation reason, never no-impact. The pure API below remains valid for identified layers. The V7 storage description at the end is historical and noncanonical. Foreground acquisition coordination is implemented behind a disabled-by-default internal gate; presentation remains separate.

`WSSIAssessment.evaluate(layers:at:time:)` is a pure Sendable seam. It returns twenty entries (four source periods, each with Overall and four components), retaining each layer's issuance and validity. Overall is evaluated directly from its source geometry. Overlap selects the highest source impact. Exterior boundaries are included; hole interiors and boundaries are excluded, matching existing polygon containment. Validity is half-open `[validFrom, validTo)` and never derived from local calendar days.

The caller supplies decoded, complete, accepted layers with explicit geographic bounds, product, period, issuance, and actual validity. The constructor rejects inconsistent feature metadata and evaluation rejects duplicate product/period inputs. Geometry must already have passed WSSIDecoder validation. This seam neither establishes publication coherence nor converts WSSIAcquisition directly into accepted data. The approved V8 contract establishes observed stability through two complete matching scans, not NOAA transactional publication.

WSSI-05 must retain per-layer product/period identity, issuance, actual start/end, accepted geographic scope, intact polygon rings including holes, feature impact, and the acceptance/provenance evidence that justifies those layers. An accepted empty layer requires independently established issuance and validity: HTTP success or an empty array supplies neither. Missing or unverified layers must be omitted and return notLoaded. No intersecting geometry inside an accepted scope returns noImpact; points outside scope return outsideCoverage even when intact polygons extend beyond it. Future and expired windows return notYetValid and expired. Missing products are not inferred from another product. Retrieval freshness is separate from forecast validity; this seam does not assign a refresh TTL.

No persisted schema, canonical acceptance policy, Home presentation, or risk-change baseline is introduced here. Fixture empty layers demonstrate the conditional consumer contract, not proof that the current NOAA service authenticates empty generations.

Historical V7 model: `WSSIForecastLayer` remains in the schema for migration compatibility only. Its mandatory dates and per-layer rows are not canonical acceptance evidence and must not feed future presentation consumers. V8 uses `WSSICacheRecord` for complete snapshot vectors, explicit observation states, revisions, retention, and issuance watermarks. Never promote a V7 empty payload into identified-empty or infer forecast no-impact from an unidentified V8 empty observation.
