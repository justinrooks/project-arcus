# WSSI geometry probe handoff

After this change is integrated, open the integration checkout in Xcode, select the SkyAware Debug scheme and the iPhone, and install and run the app once. Disconnect the iPhone and use the installed app independently; no repeated Xcode attachment is needed.

In Settings → Diagnostics → WSSI Geometry Probe, enter the verified reachable Forge development origin and the Wi-Fi conditions. On first local-network access, allow the local network prompt; if denied, enable SkyAware under iOS Settings → Privacy & Security → Local Network, then retry. Select Download + decode + persistence for each run. Pass A: select Overall Impact Day 1 when available and export the CSV. Pass B: select a larger accepted revision and export. Pass C: select available datasets one at a time, run them sequentially and export each result; extend toward all 15 only when useful. Keep each CSV and label the pass and qualitative responsiveness separately. Each run reads the live manifest; an unavailable revision is reported rather than treated as a zero measurement. Sampled process footprints are estimates, not exact peaks.

An interrupted run is restored with its last completed stage and partial observations. Cancel waits for the current operation to observe cancellation; reset is available after it finishes. Persistence uses a disposable isolated store and synthetic replacement revisions. Network conditions are self-reported in the configuration field; they are not measured automatically. Simulator results validate the workflow only and do not establish physical-device performance or memory behavior.
